## 🚀 الميزات الرئيسية للمنصة

### 1. المتجر الرسمي (Storefront)
- **الهوية البصرية والفخامة**:
  - تم استخدام نفس الهوية البصرية وشعار البراند الأسود الملكي وحرف الـ **V** الكلاسيكي من الصور المرفقة.
  - شريط إعلانات علوي: `FREE DELIVERY IN AMMAN • 1 JD ACROSS JORDAN`.
  - قسم البانر الترويجي (Hero Section): عارضو أزياء بستايل الستريت وير الأردني، الشعار العريض `VELEN`، والنصوص: `Premium Everyday Essentials. Made in Jordan.` و `CLEAN FITS. PREMIUM FEEL. BUILT FOR EVERYDAY WEAR.` مع زر `SHOP THE COLLECTION`.
  - قسم الكوليكشن (THE COLLECTION): شبكة منتجات مطابقة تماماً للصورة (2 أعمدة على الموبايل و4 على الديسكتوب)، شارة **SALE** على كل منتج، زر الحقيبة العائم الأبيض السريع، أسعار بالدينار الأردني (JOD) مع السعر المشطوب.
  - نافذة منبثقة لتفاصيل المنتج ومقاسات البوكسي فت (S, M, L, XL, XXL) ومعلومات القماش القطني 260 GSM.
  - سلة تسوق جانبية (Cart Drawer) مع مؤشر الشحن المجاني في عمّان.
  - شاشة إتمام الطلب الفوري (الدفع عند الاستلام COD / كليك CliQ) مع رسالة تأكيد مباشرة لربط الزبون برقم الواتساب الرسمي.

### 2. قسم المجتمع (COMMUNITY WEARS VELEN)
- واجهة فيديو وريلز عمودية بنسبة 9:16 مطابقة للصورة.
- تشغيل الفيديو مع زر كتم/تشغيل الصوت.
- تقييم الزبائن بالنجوم من 1 إلى 5 نجوم مع تعليق وكلام بسيط ووصف القطعة (`بنطلون مع Ringer Sky Blue`).
- زر **"شارك صورتك أو ريلز ستايلك + تقييم 5 نجوم"**:
  - يتيح لأي زبون رفع صورته أو مقطع فيديو الريلز الخاص به مباشرة إلى السيرفر.
  - اختيار التقييم بالنجوم التفاعلية وكتابة الرأي.
  - ينزل المنشور فوراً في قسم المجتمع بالمتجر!

### 3. لوحة تحكم الأدمن المستقلة (Admin Dashboard)
لوحة تحكم احترافية وشاملة للمتجر:
- ⚡ **تزامن حي وفوري (Real-Time Live Sync)**:
  - عند إضافة منتج جديد بواسطة الأدمن، يظهر فوراً على شاشات الزبائن المفتوحة للموقع دون الحاجة لإعادة تحميل الصفحة!
  - عند قيام أي زبون بعمل طلب شراء، تصدر لوحة الأدمن تنبيهاً صوتياً وإشعاراً فورياً وتحديثاً لعداد المبيعات.
- 📦 **إدارة المنتجات (Products Management)**:
  - إضافة منتج جديد (الاسم، السعر الأصلي، السعر بعد الخصم، التصنيف، الكمية بالمخزن، تفعيل شارة SALE، المقاسات المتوفرة، رفع الصورة وسحبها، ونوع القماش).
  - تعديل أي منتج أو حذفه بنقرة واحدة.
- 🛍️ **إدارة الطلبات (Orders Management)**:
  - استعراض طلبات الزبائن الواردة (الاسم، رقم الهاتف الأردني، المحافظة، العنوان التفصيلي، القطع، طريقة الدفع).
  - تغيير حالة الطلب: (قيد الانتظار 🟡 -> جاري التجهيز 🔵 -> مع المندوب 🚚 -> تم التسليم 🟢).
  - زر محادثة واتساب مباشر بنقرة واحدة مع العميل ورسالة جاهزة تتضمن رقم طلبه وتفاصيله.
- 📸 **إدارة المجتمع (Community Moderation)**:
  - مراقبة صور وفيديوهات وتقييمات الزبائن وإمكانية حذف أو اعتماد أي منشور، بالإضافة إلى نشر بوستات رسمية.
- ⚙️ **إعدادات المتجر (Settings)**:
  - تعديل شريط الإعلانات العلوي، ونصوص الهيدر، والعملة.
